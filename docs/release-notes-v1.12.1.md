# Windows Toolbox v1.12.1

This hotfix makes rapid navigation lighter and prevents an older reentrant route from replacing the current page. It also moves settings-file work off the UI dispatcher and serializes writes safely.

The Settings ComboBoxes now display localized option names. The top toolbar adds an immediate Simplified Chinese / English menu, and public Shell, Home, Settings, module navigation, and headers display one language at a time. Sidebar icon alignment and page-header spacing are refined.

Language defaults to Simplified Chinese for existing settings files. Deep module pages are not fully translated in this release. See the repository validation record for test results and manual checks that remain pending.
