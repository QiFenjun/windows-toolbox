# Windows Toolbox v1.12.0 Validation

## Scope

v1.12.0 adds Image Tools and Regex Tools as static pages inside the existing `utilities` module. The sidebar still has 11 top-level modules; Utilities has 8 internal tools.

## Image Tools

- Inputs exercised: PNG, JPEG, BMP. Encoders exercised: PNG, JPEG, BMP.
- Resize tests cover aspect-ratio fit, exact dimensions, and no-upscale behavior. Dimensions are limited to 32,768 per side and 40 million pixels; source files are limited to 128 MiB. Preview dimensions are bounded to 1,200 pixels and batches to 500 files.
- EXIF orientations 1–8 are pixel-order tested; orientation is applied before encode. Re-encoded images do not preserve source metadata, including EXIF/GPS. Transparent pixels are composited over white for JPEG and BMP.
- Source streams are closed after preview/decode. Tests rename and delete loaded inputs, preserve source bytes, verify output conflicts, cancellation and temporary-file cleanup, and exercise sequential batch progress/failure handling.
- Output uses a same-directory temporary file and non-overwriting atomic move. By default it creates a suffixed sibling output and never overwrites the source or an existing target.

## Regex Tools

- Engine: `System.Text.RegularExpressions.Regex`; every user-supplied pattern uses the timeout constructor. `Match`/`NextMatch` and `Regex.Replace` share that timeout-bearing instance; `RegexMatchTimeoutException` is caught and shown as a bounded error.
- Timeout choices are 100, 500 (default), 1,000 and 2,000 ms. Options are IgnoreCase, Multiline, Singleline, CultureInvariant and ExplicitCapture; all are off by default.
- Named/numbered groups, indices, lengths, unsuccessful groups and replacement preview are covered. Zero-length matches, Unicode, invalid patterns, match limits, cancellation, stale-result rejection and disposal clearing are also tested.
- Text soft warning: 1 MiB UTF-8; live processing is disabled at 5 MiB; hard text limit: 10 MiB UTF-8. Pattern and replacement limits: 16,384 characters each. At most 10,000 matches/replacements are processed; replacement output is capped at 10 Mi characters.
- Inputs, patterns, captures and results remain in memory for the current session and are cleared on disposal; no history is written.

## Security and privacy audit

- Image and Regex code has no networking client/API, process execution, PowerShell, `cmd.exe`, registry, telemetry or history persistence path. Image Tools writes only its output file in the source folder or the user-selected output folder; Regex Tools writes no files.
- No package dependency was added. Source image contents and metadata are not logged; Regex pattern, test text, captures and replacement output are not logged or persisted.
- Image outputs intentionally strip metadata. Input images are never modified, and existing output paths are never overwritten.
- Regex construction uses a finite timeout, match enumeration stops at 10,000, large input is bounded, and replacement expansion is checked before allocating each substituted value.
