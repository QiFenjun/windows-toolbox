# Windows Toolbox v1.9.0 validation

## Baseline

- Previous release: v1.8.0
- Previous commit: `b371ea0dee42f06d4bf0453b90ac1451ddd48781`
- Previous tests: 399/399
- Top-level Utilities module ID: `utilities`; fixed child IDs: `qr`, `color`

## Automated checks

- `dotnet build WindowsToolbox.sln -c Release --no-restore`: passed, 0 warnings / 0 errors
- `dotnet test WindowsToolbox.sln -c Release --no-restore`: passed, 468/468
- `--qr-roundtrip`: passed for ASCII, Chinese and Emoji through encode → WPF bitmap → decode
- `--ui-smoke`: passed in Light and Dark themes for all 11 top-level module views and both Utilities pages; uses no user interaction or native module activity
- Unit tests use Fake clipboard, Restart Manager, execution-state and screen picker adapters. They do not access user files or the real screen and do not request that Windows stay awake.

## Native integration checks

- `--screen-picker`: passed on a Per-Monitor V2 test thread. The test created its own RGB(10,20,30) WPF window, sampled its center 500 times, and reported 116 GDI objects both before and after. No screenshot or user window was read. The current machine's exact mixed-monitor DPI configuration was not recorded.
- `--restart-manager`: passed on self-created temporary Unicode files for locked/unlocked state, PID + start time, repeated sessions, multi-file/folder aggregation, cancellation and exceptional session cleanup. A 396-character path was explicitly rejected with native error 29 instead of being reported as unlocked. Temporary files were cleaned.
- `--keep-awake`: both native execution-state modes activated and were immediately released on the same worker thread.
- `--stress`: 20,000 empty files across 79 batches, cancellation, reparse-cycle skipping, access-denied folder behavior, ACL restoration and fixture cleanup passed.

## Safety and privacy audit

- Utilities uses the local ZXing.Net encoder/decoder and local image loader. It does not make network requests, auto-save QR input/decoded images/color history, or open decoded URLs. A QR PNG is written only after the user chooses an export path.
- ZXing.Net 0.16.11 is declared Apache-2.0 in its NuGet metadata; the source repository includes the full license text and the release packaging script includes the license plus attribution notice.
- The screen picker uses `GetCursorPos`, `GetDC`, `GetPixel` and paired `ReleaseDC`; it does not use hooks, injection, window-content APIs, screenshots, disk writes, clipboard writes, or logging of coordinates/colors. The overlay is closed on completion, cancellation, deactivation, owner hide and application exit.
- Lock Inspector remains diagnostic-only and uses Restart Manager. Keep Awake uses `SetThreadExecutionState` only and releases requests on stop, expiry and true application exit.
- Existing module IDs and previous module implementations remain unchanged.
- `scripts/publish-release.ps1` checks repository immutable-release settings before creating a tag and verifies the resulting Release reports `isImmutable=true`.
