# Windows Toolbox v1.10.0 validation

## Baseline and scope

- Previous release: v1.9.0, commit `59e291d72b1545f6f76dc7f2af8be4998dde88ad`, 468 tests.
- Repository began clean on `main`; final implementation adds Time Tools and Random Tools inside existing Utilities (`utilities`). No new Sidebar module or dynamic tool/plugin loader was added.
- QR Tools and Color Tools business logic remains unchanged.

## Build and tests

- Release build: 0 warnings, 0 errors.
- Release tests: 497/497 passed.
- Time conversion/current-time tests use fixed clocks and a fake timer; clipboard checks use a fake adapter. Random string/integer unit tests use a deterministic fake secure-random source. `dotnet test` does not set a real sleep-prevention request or alter the real clipboard/system clock.

## Integration checks

- `--ui-smoke`: Light/Dark WPF resources/layout for all 11 top-level module views and QR, Color, Time, Random pages; verifies all four static Utilities navigation templates and 560-DIP Time/Random layout without horizontal scrolling.
- `--qr-roundtrip`: real local QR encode/decode for ASCII, Chinese and Emoji.
- `--secure-rng`: production `RandomNumberGenerator` smoke checked 100 UUIDs, 100 strings and 100 integers; an additional 1,000 × 128-character batch completed in 8 ms. Values were not printed or saved. This is not a statistical randomness or password-strength test.
- `--screen-picker`: sampled only the integration's own RGB(10, 20, 30) test window 500 times; GDI object count remained 118 → 118. No screenshot or user window was read. Native libpng emitted non-fatal embedded-profile warnings during this check.
- `--restart-manager`: real Unicode locked/unlocked temp file, PID + process-start identity, multi-file/folder scan and cancellation/error session cleanup passed. The 396-character path was explicitly unavailable (native error 29), never reported as a clean no-blocker result. Temporary fixtures were removed.
- `--keep-awake`: both execution-state modes were immediately released on their owner thread; no long-duration sleep-prevention test was performed.
- `--stress`: 20,000 temporary empty files, 79 batches, cancellation, junction skip, access-denied handling, ACL restoration and fixture cleanup passed.

## Security and privacy audit

- Time Tools uses `DateTimeOffset`, UTC Unix epoch, invariant ISO parsing, and the local Windows `TimeZoneInfo` database. DST gaps are rejected; ambiguous wall times expose both offsets and require a choice. No system time/timezone modification, network time service or conversion-history persistence was found.
- Random Tools uses `Guid.NewGuid`, `RandomNumberGenerator.GetInt32`, and `RandomNumberGenerator.Fill` with rejection sampling for inclusive integer ranges. No `System.Random`, online random source, result persistence, secret logging, registry access, shell command, or telemetry path was found in the new Time/Random production sources.
- Random string bounds: 1–4,096 characters, up to 1,000 entries, combined output at most 1 MiB. Generated results are in-memory only and are cleared when its ViewModel is disposed.
