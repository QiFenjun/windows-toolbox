Windows工具箱 v1.0
===================

当前功能
--------
1. 自定义日期和时间安排 Windows 关机
2. 30 分钟、1 小时、2 小时、今晚 23:00 快捷设置
3. 实时显示计划关机时间和剩余时间
4. 一键取消 Windows 的待执行关机计划

使用方法
--------
直接双击“Windows工具箱.exe”运行，无需安装。

注意事项
--------
- 设置完成后，关闭本软件不会取消关机计划。
- 若要取消，请重新打开软件并点击“取消关机”。
- 请在关机前保存正在编辑的文件。
- 软件不会强制关闭应用；若有程序阻止关机，Windows 会显示相应提示。
- Windows Defender/SmartScreen 可能提示这是未知发布者，因为此 EXE 未购买代码签名证书。

技术说明
--------
本软件调用 Windows 自带的 shutdown.exe 完成安排与取消操作，不联网、不收集数据。
源码文件 WindowsToolbox.cs 已随软件一并提供。
